HQ Studio: Privacy Policy

Last updated: 10 November 2026

Who this covers

HQ Studio is a private tool used only by its owner, with the owner's own accounts. It has no other users and collects no data about anyone else.

What it stores

  • Sign-in tokens issued by each platform (for TikTok: an access token, a refresh token and the account's open ID), so it can upload approved videos without asking to sign in every time.
  • The account's display name, only to show which account is connected.
  • Upload results (for example a TikTok publish ID and its status), so a video is never sent twice.

Everything is stored only in files on the owner's own computer, readable only by the owner. Nothing is stored on any server run by HQ Studio, because there is none.

What it does not do

It does not read messages, followers, contacts, analytics of other people, or any other user's data. It does not sell, share or transfer data to anyone. It uses no advertising and no tracking.

Which permissions it uses on TikTok

  • user.info.basic: to confirm which of the owner's accounts is connected.
  • video.upload: to send an approved video to the owner's TikTok inbox as a draft.

Deleting data

Revoking access in the platform's settings stops all access immediately. The owner can also delete the token files on their computer at any time, which removes everything HQ Studio stored.

Changes

If this policy changes, the date above is updated.
